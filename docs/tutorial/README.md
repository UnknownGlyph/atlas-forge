# 从零创作远洋人民共和国及四邻国

在软件中打开「帮助 → 创作教程」，或按下面顺序阅读。每章有阶段图、分步配图入口、验收方法和排错提示。前 12 节完成一个可编辑的五国地图；后 10 节练习从数据和气候到资料库、脚本及发布的进阶工作。

## 练习材料

- [五国成品工程](yuanyang.atlas)，打开时远洋洲居中。按 Home 恢复打开视角。
- [五国边界](countries.geojson)、[64 个一级行政区](provinces.geojson)，可通过共享边界模式导入进行练习。
- [全图 PNG](11-atlas.png)、[全图 SVG](yuanyang.svg)、[腹心区行政详图](12-districts.png)。
- [2897 年辖区与城市统计](yuanyang-2897-data.csv)、[远洋资料](yuanyang-data.json)、[四邻国资料](allies-data.json)。CSV 为阅读表，含上下级代码、等级、人口、GDP 和来源。

## 课程

1. [从白画布规划版面](chapters/01-paper.md)

    先得到一张有大陆、首都和外岛位置关系的构图草稿。

2. [从方位起稿，细画海岸](chapters/02-coast.md)

    把方位草稿做成真实的地理轮廓，建立半岛、海湾和离岸岛链。

3. [建立五国与共享国界](chapters/03-countries.md)

    把一套海岸划分为七个国家，并检查它们的接壤关系。

4. [建立 42 个一级行政区](chapters/04-provinces.md)

    建立正确的从属关系，同时用分级字体区分国名、省级名和更低级的地名。

5. [在独占层布置七大地理区](chapters/05-regions.md)

    保留政治行政区，同时为区域分析和专题输出建立七区。

6. [画山脊、水系和运河](chapters/06-water.md)

    从地貌解释河流为什么这样流，建立可以分别检查的自然要素图层。

7. [安放首都、省会和交通](chapters/07-cities.md)

    让城市层级和交通网络和行政、河口、山地位置对应。

8. [制作半岛并入的前后年份](chapters/08-history.md)

    每次改归属都能在明确的年份重放，并带有可打开的事件。

9. [录入远洋互助协约](chapters/09-diplomacy.md)

    建立可按年份查阅的五国协约，并关联缔结事件。

10. [给龙吟港关联详图与文档](chapters/10-board.md)

    从地图对象进入自己的白纸详图，并用文档作为第二个入口。

11. [复核地图并完成导出](chapters/11-export.md)

    交付一份保存好的工程，以及一张可供展示的最终地图。

12. [细绘地级市、地区与县级市](chapters/12-districts.md)

    在同一套行政边界上，从国家逐级划到县级，并给每一级落下可搜索的城市点。

13. [控制二维、三维与显示层级](chapters/13-navigation.md)

    从全洲定位到任意县级辖区，在二维和球面之间维持方位。

14. [设置保存点、自动保存和撤销](chapters/14-checkpoints.md)

    能对不同阶段精确回退，同时保留当前已保存的 .atlas。

15. [导入边界、数据和参考底图](chapters/15-imports.md)

    掌握共享边界导入、独立岛屿导入、按编号接合 CSV 和参考图配准。

16. [填入人口与 GDP，制作专题图](chapters/16-data.md)

    用带年份和来源的数值支撑国情、辖区和城市对照，再将数值做成地图。

17. [组织线路、标注、符号和要素图层](chapters/17-features.md)

    用独立要素图层建立水系、交通、地貌、标注四套可单独导出的表现。

18. [从基础气候到人工修订](chapters/18-climate.md)

    演练空白世界的纬向气候、五国图局部雨影差异和创造性的修订。

19. [用星图设定本恒星系、月球和银河](chapters/19-stars.md)

    安排恒星系与月球的时间和光照，并把工程行星放到星系中。

20. [将地图、事件和文档编成资料库](chapters/20-library.md)

    建立一个可导航、带随文图片并能批量导出的资料体系。

21. [使用 AI 助手、本地脚本和插件](chapters/21-automation.md)

    同一份副本分别用在线模型草稿、纯本地脚本和声明式插件试写属性。

22. [稽核边界、安排版式与发布](chapters/22-review.md)

    把可编辑工程、定稿、历史图和数据表整理成能交接的文件。


## 地图口径

示例选取远洋人民共和国、麦伦、东升、辛加尔和皮斯。原七国图的另两国不再作为政治实体；旧版所占陆地并入相邻远洋辖区，保留连续海岸。远洋 42 个一级行政区，四邻国 22 个。350 个城市点包含 4 个远洋直辖市、70 个地级市、20 个地区、234 个县级市和 22 个四邻国驻地。远洋的地级、县级及四个直辖市均有可编辑辖区。

五国国家总量和远洋 42 区、邻国一级区的面积与人口来自地理志。四邻国的省级 GDP 按人口并结合设定产业描述分摊；远洋下辖地、县级统计按地理面积与驻地权重分配，城区单列估算。远洋必要 GDP 与邻国的全口径 GDP 在数据来源中注明。绘制几何的实算面积与原始设定面积分列。

制图格网用于确定相对方位，海岸与内部边界采用连续曲线重绘。地图新添的地、县级名称、辖区和统计属于本教程的细化设定。

在源码目录使用以下命令可重新生成地图、GeoJSON、统计表和 01–12 阶段配图。其余配图来自软件操作界面。

~~~powershell
.\tools\cargo-msvc.cmd run --locked --release -p map_io --example yuanyang_tutorial
~~~
