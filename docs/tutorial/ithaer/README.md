# 在创作工作室里完成伊瑟尔三国

本教程以本地工程「伊瑟尔星 2897 · 远洋洲与伊瑟尔三国」为例，在创作工作室中完成浏览、查找、改归属、画边界、加河流与城市、做标志、记历史、填数据、写资料和导出。软件内的「帮助 → 创作教程」与本目录使用同一份内容（[lessons.json](lessons.json)）。

## 准备

- Atlas Forge 0.2.4 Alpha 或更新版本，界面切换到创作工作室（Ctrl+Alt+F10）。
- 实操时需要另备伊瑟尔三国 `.atlas` 工程。在创作工作室点「帮助 → 打开伊瑟尔三国测试工程」，如未自动找到，则选择本地的 `伊瑟尔星2897_远洋洲与伊瑟尔三国.atlas`。载入后可另存为自己的练习文件。教程正文和配图可直接查看。
- 工程概况：伊瑟尔人民共和国（IT，36 个一级行政区，首都米斯瑞市）、埃兰特议会共和国（EL，28 个，首都古圣市）、秋津国（AK，20 个，首都秋津都）；旧都伊瑟尔市位于 0° 经线、北纬 29.52°；北回归线参考线位于北纬 23.436°；打开视角为等距圆柱投影、中央经线 131.5°E；当前年份 2897，纪年为伊瑟尔纪元。同一工程还包含远洋洲五国，可在完成本教程后继续练习。

## 课程

1. [打开伊瑟尔三国，认识创作工作室](chapters/01-studio.md)

    打开伊瑟尔三国工程，认清创作工作室的五个区域，知道每类操作从哪里开始。

2. [查找地点，控制视角](chapters/02-find.md)

    用查找和视角菜单在三国之间快速定位，并认识两个地理基准：伊瑟尔市所在的 0° 经线和北回归线。

3. [读懂三国的行政层级](chapters/03-hierarchy.md)

    弄清三个国家、84 个一级行政区与驻地城市的上下级关系，学会用属性面板检查任意一级。

4. [用领土画笔改变归属](chapters/04-territory.md)

    在指定年份把埃兰特的交界市划给伊瑟尔的四方省，同时保证 2897 年的地图不变。

5. [切分、重画与合并边界](chapters/05-borders.md)

    在秋津国内部练习切分、重画国界、编辑顶点与合并，理解共享边界：一条边只存一次，两侧一起变化。

6. [河流、线路与城市](chapters/06-rivers.md)

    为伊瑟尔腹地画一条河，在旧都与首都之间连一条道路，并在合适的位置添加城市。

7. [地图文字、符号与像素标志](chapters/07-marks.md)

    在秋津国附近加一处海湾名称，为秋津都放置自绘的像素旗帜，并整理首都符号所在的图层。

8. [时间轴、事件与外交](chapters/08-history.md)

    把第四章的领土变化写成一个事件，在历史页回放它，并在外交关系中记录三国之间的协约。

9. [数据表与专题图](chapters/09-data.md)

    查看三国在 2897 年的面积、人口和必要 GDP，用人口做一张分级设色专题图，并为行政区补充数据。

10. [世界资料与独立画板](chapters/10-library.md)

    为伊瑟尔三国写一篇概况文档，与地图上的国家关联，再为秋津都建一张城区画板，并能在它们之间来回跳转。

11. [保存点、版式与导出](chapters/11-export.md)

    在交付前设置保存点，复核地图，再导出一张与工程配图同范围的伊瑟尔三国行政详图。

## 关于配图

地图配图裁自工程目录中由导出器生成的「伊瑟尔三国行政详图」，再加上标注。标为「示意」的线条、旗帜、名称、窗口和对话框是为讲解绘制的，不是工程原有内容，也不是软件截图；界面以实际运行为准。

上一版以远洋人民共和国为例的二十二节练习保留在 [../README.md](../README.md)。
