# 性能基准

## 多画板与嵌入附件的整文件存储

运行 `map_bench storage <子画板数> <每份附件 KiB>`。每张空白子画板链接一份独立、可复现的伪随机二进制附件。每次只改项目标题，再走正常文件保存和加载入口，逐份比对附件、链接、画板数和标题。下表为 Windows x64 Release 构建，同一进程运行六轮并排除首轮的时间中位数。峰值为整个进程的 Windows 工作集，包括原文档、校验用回读文档和编解码临时分配。

| 子画板数 | 每份附件 | 文件字节 | 保存 | 加载 | 峰值工作集 |
|---:|---:|---:|---:|---:|---:|
| 12 | 256 KiB | 3,161,629 | 9.78 ms | 2.48 ms | 15.16 MiB |
| 100 | 0 KiB | 5,943 | 5.44 ms | 0.99 ms | 6.37 MiB |
| 100 | 256 KiB | 26,331,060 | 45.35 ms | 19.28 ms | 85.24 MiB |
| 100 | 1,024 KiB | 105,282,665 | 161.66 ms | 68.75 ms | 316.73 MiB |

这个对照中，嵌入数据量主导了开销。真实地形、模型解码和图片纹理还有各自的成本。带旋转备份的手动保存及实际存储设备也会影响落盘时间。

## 0.2.5 Alpha · 大地图交互与模拟

本轮使用 Windows x64 Release 构建。基线为 0.2.4 发布后的审查提交 `379ed2d`，地图为 1,177 个面、2,755 条边的完整伊瑟尔星工程。下表分别计量各项操作，耗时为中位数。

| 操作 | 基线 | 0.2.5 Alpha |
|---|---:|---:|
| 10,000 次视口空间查询，混合小范围、大范围和跨日界线范围 | 1.929 秒 | 0.157 秒 |
| 全球环境生成，256×128 | 269.9 ms | 47.5 ms |
| 局部环境生成，505×512 | 1,341.0 ms | 262.4 ms |
| 跨日界线的局部环境生成 | 108.3 ms | 27.5 ms |
| 标准类地行星的十二个月气候求解 | 10.65 ms | 3.24 ms |
| 稳定画面刷新一次 CPU 几何缓存 | 2.894 µs | 0.069 µs |
| 单点编辑或撤销后的 CPU 几何缓存刷新 | 4.416 ms | 4.209 ms |
| 地形阴影生成，1440×720 合成高程栅格 | 70.1 ms | 18.5 ms |

环境与气候各用三个场景，预热一次后新旧版本交替运行七对。逐格核对全部环境字段、流向和适宜性，逐月核对三类行星的气候结果。六组输出均逐字节一致。视口查询的命中地块摘要一致，地形阴影还比较了单行、单列、极区、不同半径和强度的 RGBA 输出。

在同一完整工程上增加 60 个绘制层和 2,400 个文字标注，使用固定的 96 帧分屏平移和旋转轨迹复测最终版本。交替六轮并排除首轮，重载工程的桌面 CPU 帧中位耗时由 31.553 ms 降至 19.321 ms，P95 由 36.667 ms 降至 23.083 ms。原始工程为 1.085 → 0.948 ms，P95 为 1.500 → 1.490 ms。两组界面顶点及索引总数一致。另对六个手工摆放的国名验证字号与地图边缘裁剪，均与基线一致。这些数字涵盖界面布局与三角化，显示器同步和 GPU 等待单独测量。

另用约 17.9 MB、12 个画板的工程测试备份落盘与重开。新旧保存结果的 SHA-256 相同，磁盘实测有波动，本轮没有测得稳定的磁盘保存加速。恢复元数据写入失败后，下一次自动保存会补写恢复文件，已经成功的历史保存点仍只有一个。

几何缓存用 `map_bench scene-refresh <工程.atlas>` 复测。每轮重复 2,000 次稳定刷新和 40 对边界修改与回退，取九轮中位数。桌面双视图的 CPU 回放可运行 `cargo test --release -p map_app --bin atlas desktop_pan_and_rotate -- --ignored --nocapture`，环境变量 `ATLAS_BENCH_WORLD` 指向待测文件，`ATLAS_PREFS` 指向禁用自动保存并指定独立缓存目录的测试偏好。回放包含编辑器布局、地图标注与界面三角化，GPU 回读另用 `globe_frames` 检查。

实际创作时的互动、资源占用和慢帧可用[性能录制工具](PERFORMANCE_RECORDER.md)记录。

运行：`tools\cargo-msvc.cmd run -p map_bench --release`（合成网格世界，种子固定，可复现）。
