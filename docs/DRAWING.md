# Atlas Forge 绘图功能总览

本文概括 M4 阶段完成的绘图能力（细节与验证记录见 `ARCHITECTURE.md` 的 M4 各步）。

## 一、领土与地形（改变地图本身，遵守年份规则）

| 工具 | 作用 |
| --- | --- |
| 绘制陆地 L / 绘制湖泊 K | 单击加点、拖动手绘或画笔涂抹；吸附并沿已有边界描线；线条风格（原样、平滑、自然化）可保持面积；选定年份时为“从该年起”的变化 |
| 切分 / 画边界 S | 沿新线切分地块 |
| 重画国界 G | 画出新国界，两国之间的土地从选定年份起易手 |
| 编辑顶点 E | 拖动、插入、删除顶点；选定年份时可作为领土变化 |
| 领土画笔 B、合并相邻面 M | 归属指定与地块合并；填充（Shift+单击）把相连的同归属陆地整片交给画笔国家 |
| 添加城市 C | 放置、移动、删除城市 |
| 整理地块（编辑菜单） | 合并历史完全相同的相邻地块 |

历史保护：较晚年份的编辑不改变较早年份；改变所有年份的重塑先预览，可保持面积。

## 二、版面要素（不改变领土；可选年份范围）

| 要素 | 工具 | 主要能力 |
| --- | --- | --- |
| 河流 / 线路 | 河流 / 线路 R | 实线、虚线、点线；终点箭头；粗箭头（渐宽色带，可空心）；前线锯齿、铁路横线；沿线标注名称；吸附同类线端点、线上与城市，从端点延长 |
| 曲线 | 钢笔 / 曲线 P | 用贝塞尔曲线画河流、线路或斜线区域：单击放尖角，按住拖动拉出控制柄；拖动锚点与控制柄修改，双击切换平滑/尖角或加锚点，右键删锚点；已有的线与区域可转为曲线 |
| 斜线区域 | 斜线区域 H | 斜线、交叉线、点三种图案；底色、虚线边框；可含多块与洞；可从国家某年的疆域生成；合并、减去、相交 |
| 地图符号 | 地图符号 Y | 十二种矢量符号（山峰、火山、关隘、战役、营地、要塞、首都、港口、灯塔、寺庙、矿山、遗址）与任意字符符号；名称可放上下左右 |
| 地图文字 | 标注 T | 字号随地图比例；字体（本机字体，中文名可搜索）与粗体；角度、字距、斜体；弧形排列或沿手绘曲线排列 |
| 国家标注 | 标注 T | 自动：沿国土主轴的弯曲线，字号随国土大小，长线上铺开字距，避开城市点；球面上贴着曲面；手动放置、旋转、缩放、隐藏或恢复自动 |

通用操作：
- 样式：线路、斜线区域、地图文字、符号可以使用命名样式（"样式"标签的样式库，可添加常用样式）；修改样式，使用它的全部要素一起改变；在一个要素的面板里改外观也会改变它的样式（先"脱离样式"则只改它自己）。选项栏可选新画要素的样式；吸管工具（I）把样板的外观给所选要素；色板收集常用颜色。
- 选择工具拖动所选线路、河流或区域整体移动（在球面上旋转，保持真实形状与大小）；Ctrl+D 复制。
- 编辑顶点工具也可编辑河流、线路与斜线区域主轮廓的点；曲线则编辑其锚点与控制柄。
- “图层”标签：上半是图层栈——把要素分组，整组显示、隐藏、锁定、调不透明度，上面的图层盖住下面的（Ctrl+G 把所选建为图层；单击图层名设为当前图层，新画的要素进入它）；不在图层里的要素在最下面，照原来的顺序绘制。下半按种类列出全部版面要素，筛选、选中、定位，逐个或按种类显示 / 隐藏（隐藏的要素不绘制、不导出、不进图例）。
- 测量 D：沿大圆测距离，闭合后给出面积（按本星球半径），不保存。

## 三、导出与数据

- 与应用中一致的绘制：所有符号、线型、图案与文字由同一套核心计算生成。
- 图例：国家或专题分级；线路与区域按“图例说明”加入（同说明同样式合并），符号按种类或说明加入，样例画成要素本身的样子。
- 可选比例尺（图中心比例；全球图注明仅适用于图中心附近）与指北针。
- 版式：把尺寸、投影、范围、标题与图面要素存为版式，一键套用；多个版式按年份导出为地图集（含 index.html 目录页，可共用同一图例尺度）。
- 专题图可选“各年统一”分级，使逐年导出、动画与地图集中同一颜色代表同样的数值。
- 矢量数据：GeoJSON 与 Shapefile 的导入导出（Shapefile 只读写经纬度坐标）。
- 缺字时使用系统符号字体回退。

## 四、已知限制

- 斜线区域只有主轮廓可逐点编辑；由国家生成或运算得到的其他块与洞不能单独编辑。
- 区域在球面上部分位于背面、或在平面图跨经线时只画边线，不画斜线与名称。
- 沿曲线排列的文字在曲线于屏幕上太短时按原角度显示。
- 比例尺与指北针只在导出中提供，应用视图中没有。
- 应用中的字符符号使用界面字体，个别罕见符号可能无法显示（导出已有回退字体）。
- 快速连续点击后双击结束绘制：已修复已知原因（三击计数），但有一次未能复现的失败。

## 五、之后

实体存续期、跨年份统一分级、版式与地图集、Shapefile 读写已完成（`ARCHITECTURE.md` M4 第三十四至三十七步）；GDAL/PROJ 暂不接入（理由见第三十七步）。“按证据推进”的性能项已用测试世界衡量并处理（第三十八、三十九步）：按年份的边界与海陆修改都局部重建，几何多版本暂不需要；约百万三角形的精细测试世界在应用中约 8 ms 一帧。长期目标见 `ARCHITECTURE.md` §9（AI 原生创作能力、复杂多层测试地图）。
