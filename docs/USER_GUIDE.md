# Atlas Forge 使用说明

Atlas Forge 是绘制架空世界与历史地图的桌面程序：在同一张地图上画陆地与国家，让国界、海岸、归属随年份变化，再导出成品地图。本说明介绍常用的做法；每个命令的说明也可在程序中按 **Ctrl+K**（命令面板）或 **F1**（快捷键一览）查看。


[双界面、世界观、环境生成、图表与时间视频](CREATION_WORKSPACES.md)

## 1. 安装与启动

- 解压 `AtlasForge-版本-windows-x64.zip`，双击 `atlas.exe` 即可运行，无需安装。
- 需要支持 DirectX 12、Vulkan 或 OpenGL 的显卡。无法启动时会弹出说明：更新显卡驱动；远程桌面或虚拟机中可能没有可用的图形设备；也可设置环境变量 `WGPU_BACKEND=dx12`（或 `vulkan`、`gl`）后再启动。
- 界面与导出的默认字体是随附的思源黑体开源版 Noto Sans SC（`fonts` 文件夹，SIL 开放字体许可）；缺少该文件夹时改用系统中的中文字体（微软雅黑、黑体等）。地图中的名称也可以选用系统里安装的任何字体。
- 检查程序是否正常：在命令行运行 `atlas.exe --self-test 某个文件夹`，会生成一个世界、做一次自动划分与道路、保存并读回、导出 PNG/SVG/PDF，报告写在该文件夹的 `自检报告.txt`。
- 用 `.atlas` 文件打开：把文件拖到 `atlas.exe` 上，或在命令行 `atlas.exe 世界.atlas`。

## 2. 界面

「帮助 → 创作教程…」从空白开始绘制远洋人民共和国。22 节各有操作、验收和排错，单独的「阶段大图」页可以切换适合窗口和原始尺寸。点击工具入口会先收起教程，返回地图跟做。[图文教程与练习素材](tutorial/README.md)

- **左侧工具栏**：选择、画陆地、扩张、夺取、挖湖、分配、切分、线路与河流、标注、符号、测量……；鼠标停在图标上显示名称与快捷键。
- **顶部选项栏**：当前工具的选项。
- **中间**：二维地图与三维球体（"视图"菜单可只看其一）。滚轮缩放，按住空格拖动平移（任何工具中都可用）。
- **中央经线**：从顶部点击经度输入数值。正值为东经，负值为西经。点击「居中」重新对准二维和球体视图中的同一条经线。在「视角」中可选 0° 或把这条经线记为工程打开视角。
- **缩放与细节**：全图优先显示国界、国名和首都，放大逐步出现省界与省名、下级行政区、普通线路和城镇。地图点击会选中当前尺度的行政单位。可在「视图 → 按缩放显示细节」关闭分级显示，进行全图精细编辑。专题设色按当前数据字段绘制。导出由版式和导出设置控制。
- **右侧面板**：国家、数据表、字段、专题图、样式、图层、参考图等标签页；选中对象时显示其属性。
- **底部时间轴**：打开后地图显示所选年份，修改从该年起生效；关闭时显示最新状态。
- **状态栏**：坐标、比例、提示与撤销步数。

## 3. 从零开始：新世界向导

"文件 → 新世界向导…"：设定星球半径、陆地比例、大陆数、粗糙度、国家数、名称风格、河流数、是否放首都、是否生成一段随机历史，以及种子（同一种子得到同一个世界）。生成的大陆、国家、河流、地形都可以继续手工修改。

## 4. 画地图

- **画陆地 / 挖湖**：用多边形工具画出新的陆地或水域；与已有陆地重叠的部分自动合并。
- **扩张 / 夺取**：给所选国家画一块区域——扩张只占无主陆地与海，夺取连邻国的土地也一并取走。
- **分配**：点击地块把它分给所选国家。
- **填充桶**：把同一国家相连的一片地块整体改归属。
- **切分 / 合并**：沿一条线切开地块，或合并两个地块。
- **吸附**：画线时会吸附到已有的边、节点与参考线（按住 Ctrl 临时关闭）。
- **撤销 / 重做**：Ctrl+Z / Ctrl+Y；"历史"面板可跳回任意一步。

### 整体移动陆块

打开「工具 → 整体移动陆块」，按住陆地拖动。蓝色轮廓显示目标位置，松手后通过检查才会提交。选中一块后，Shift+单击可纳入其他独立陆块。拖动中按住 Shift 限制为单一经纬轴。也可以在工具栏输入精确经度与纬度偏移，再点「应用偏移」。按 Esc 退出，Ctrl+Z 撤销一次移动。

共享边界、内陆湖、辖区归属和历史记录一同保留。陆地上的城市、图形和相关资料定位点随块移动。偏移按经纬度计算，因此跨纬度移动后的实际球面面积会变化。与另一陆块相交、越过极点、关联线路两端只选一端、附属要素被锁定或固定地理数据受影响时，状态栏会写出拒绝原因。

### 地理参考线

打开「视图 → 地理参考线…」添加经线、纬线或北回归线。参考线可以独立设置颜色、显示、吸附和导出，应用后随工程保存。绘制时已有边界优先吸附，按住 Ctrl 临时关闭吸附。地块移动或切换中央经线时，参考线仍处在原有经纬度。

### 整体缩放陆块

打开「工具 → 整体缩放陆块」，点选一片封闭的连续陆地。输入百分比或相对缩放中心拖动鼠标，蓝线预览缩放后的轮廓。按「应用缩放」或松手时会检查冲突。海岸、内部共享边界、湖泊和附着的城市与要素一起缩放，历史归属保留。新位置与独立陆地相交时，状态栏说明原因并取消这次操作。

## 5. 年份与历史

- 打开时间轴（Ctrl+T），选择年份后再修改：修改只从该年起生效，更早的年份不变。
- 国家可设成立与终止年份、继承者；上级关系（省属于国家）也可随年份变化。
- **事件时间线**（"时间 → 事件时间线…"）：给一年或一段年份起名（战争、条约），在时间轴上显示，可导出编年表。
- **局部视图**：选一块区域和一段年份，独立查看那里的变化（不影响图层），可播放。
- **自定义纪年**：只改变年份的显示方式（如"开元 3 年"）。

## 6. 国家、地区与名称

- **省份**：选中国家后，在右侧点「绘制省份」，画出范围后按回车。使用「用选中地块建省份」可直接分配整个地块。两种方式都只划入国家直接管辖的陆地。省份列表可打开下级，通过「上级」返回。选中省份后可继续建立下级地区。
- **自动划分**：点「自动划分省份…」并选数量，预览后应用为一步撤销。可要求面积大致均衡、尽量沿河流与山脊。湖泊、他国飞地和已有省份保持原样。需要划为新国家时，用属性面板的「自动划分…」调整类型。
- **名称生成器**（"工具 → 名称生成器…"）：按风格生成国名、城市名、山河名；国家与城市名称旁的"随机"按钮直接改名。
- **名称风格**：每个单位可设一种名称风格；文化等分区层中的单位设了风格后，位于其中的城市与国家随它起名。
- **自动配色**：相邻国家不同色，一键重配。

## 7. 分区层与数据

- 除政治层外，可建文化、宗教等分区层；比例层中每个地块可按百分比分属多个单位。
- 选中独占层或比例层后，修改「层名称」，按回车或点击别处提交，按 Esc 取消。改名可撤销。
- 数据字段（人口等）可随年份变化，在"专题图"中做分级设色。
- 数据表可导入导出 CSV；也可导入 GeoJSON、Shapefile。

## 8. 线路、道路与旅行

- **线路**：画行军路线、商路、航线、铁路等；可设箭头、虚线、宽箭头、装饰（前线锯齿、铁路横线、山峰、树木）。
- **道路网**（"工具 → 道路与旅行…"）：在城市之间自动生成道路（绕开海与湖，陡坡代价更高），预览后应用为线路。
- **旅行**：在同一窗口选起点与终点城市，显示沿线路的路程与步行、车队、骑马、驿马所需天数；测量工具和所选线路也显示天数。

## 9. 外观

- **样式**："样式"标签页中可改海洋、陆地、边界、河流、标注的外观；**地图主题**（现代、古典图集、羊皮纸、深色）一键切换。
- **命名样式与色板**：线路、区域、文字、符号可共用命名样式，改样式即全部更新。
- **区域图案**：斜线、交叉线、点、山地、森林。
- **地形晕渲**：向导生成的地形可显示为晕渲，可调强度。
- **国名**沿国土弯曲并贴合球面；可用标注工具拖动到指定位置。
- **行政区分级字体**在「样式」中开启。国名优先用黑体，省级以宋体区分，市县用楷体，基层和城市用较小的无衬线字。二维、三维与导出使用相同的分级规则。缺失字体时使用默认字形，字号仍区分层级。

## 10. 导出与版式

- "文件 → 导出…"（Ctrl+E）：PNG、SVG、PDF、GeoJSON、Shapefile、CSV；可逐年导出、导出动画（需要 ffmpeg）、按版式导出地图集。
- **版式视图**（"文件 → 版式视图…"）：按导出的样子显示整页，拖动标题、图例、比例尺、指北针；添加插图框（显示另一区域的小地图），拖动或拖右下角改大小。位置随导出设置保存，也可存为版式。

## 11. 保存与恢复

- 工程文件扩展名为 `.atlas`。每次保存会把被替换的旧文件留作 `.atlas.bak1`（更早的为 `.bak2`、`.bak3`）。
- 在「文件 → 保存点与自动保存…」给当前工程创建命名保存点。恢复是一步可撤销的编辑；按 Ctrl+S 后才写入主工程。
- 在偏好设置中启用后台保存，设时间间隔、每隔多少次提交编辑时保存及保留的自动版本数。编辑步数为 0 时只按时间触发。自动版本轮转不会清理命名保存点。
- 版本保存在工程旁的 `.atlas.history` 文件夹。移动工程时，可以一起复制该文件夹。首次保存会把该草稿的记录带入工程版本目录。
- 程序意外退出后，下次启动会提示恢复未保存的工作。

从空白工程跟做可用[五国创作教程](tutorial/README.md)。教程含 22 章步骤、配图与练习材料。

## 13. 给脚本与 AI 用的接口

- AI 助手以独立窗口打开。可移动窗口并保留最近的提问记录，同时继续在地图窗口操作。绘图助手仍以草稿形式交付改动。
- 「工具 → AI 助手…」分为**绘图助手**和**通用助手**。前者运行原有草稿流程，最终由用户采用。后者可以用自然语言问操作、检查当前拓扑或建议工具，点推荐按钮能切换到该工具。
- 通用助手默认使用本地操作帮助与数据检查，无需密钥。启用联网回答后沿用选定的提供方，仅发送提问和所需的操作上下文。

- `atlas-query.exe`：在命令行查询工程文件（国家、面积、年份变化等），输出 JSON。
- `atlas-mcp.exe`：MCP 服务器，供支持 MCP 的 AI 客户端读取地图。
- `atlas-script.exe`：在本地用 JSON Lines 查询、编辑草稿，或批量运行脚本和插件命令。Codex、Claude Code 可直接调用命令行或接入 MCP。[脚本与 AI 接口](API.md)
- 「工具 → 本地插件…」：打开插件清单、预览改动并作为一步撤销应用。[插件编写说明](PLUGINS.md)

## 14. 行星环境与气候

从「工具 → 行星环境与气候…」运行一次模拟，或开启实时更新。用「气候图」切换逐月参考层，「地表与修订」指定海拔、修改或固定区域，「方案与导出」比较方案并输出 PNG 或 CSV。操作示例、单位与分辨率见[气候使用说明](CLIMATE.md)。

## 15. 星图

[星图、自定义天体、引力模拟和真实恒星目录](ASTRONOMY.md)

点击菜单栏的「星图」，可以在本恒星系和银河系之间切换。拖动旋转视角，滚轮缩放，单击球体或从右侧下拉表选择天体。单击银河系里标出的本恒星系可回到恒星系视图。「返回地图」或 Esc 回到制图界面；地图中的球形视图在拖动松手时会轻微滑行。

在密集地图的球形视图中，拖动和滑行会自动使用简化标注。停下后恢复完整标注和可拾取的边界。

本恒星系以太阳系为模板，当前地图的行星取代地球，球体表面使用所选年份的海陆地图。「从当前行星和气候读取参数」沿用工程半径和已配置的气候参数。可以修改恒星、添加行星、调整轨道与自转，暂停播放或改变时间速度。光照来自中心恒星；位置使用简化的开普勒轨道，球体和轨道距离采用示意比例。

银河系采用简化的三维棒旋盘面，可修改旋臂、盘面半径和本恒星系的位置。按「应用到工程」后，参数随 `.atlas` 文件保存。包含自定义星图的工程需要支持格式 3 的版本。「帮助 → 关于 Atlas Forge」可查看版本、许可证和项目链接。

模板参考 [NASA 太阳系资料](https://science.nasa.gov/learn/basics-of-space-flight/chapter1-2/)及 [NASA 银河系简介](https://science.nasa.gov/learn/basics-of-space-flight/chapter1-1/)。

### 地月系

在「星图 → 地月系」中可旋转观察当前工程的行星和月球。用「朝向恒星」把恒星转入视野，画面边缘也会提示视野外的恒星方位。恒星与远方星系属于天空背景，缩放和跟随只作用于行星与月球。

默认月球使用近似现实轨道。开启「光照」可查看昼夜、月相和两球互投的阴影。「下一次日食」与「下一次月食」沿当前轨道搜索，并暂停在食现象附近。缩放用示意尺寸，阴影按双方实际半径、距离及恒星视大小估算。月球参数应用后随工程保存，自定义月球使用格式 4。[月球模板参数](https://science.nasa.gov/wp-content/uploads/2023/09/Earths-Moon.pdf) · [日食和月食的几何](https://science.nasa.gov/moon/eclipses/)。

## 16. 世界资料与独立画板

- 选中资料中的画板、文档或地图对象后可导入模型并建立关联。通过模型附件链接打开独立查看器，左键拖动旋转，右键拖动平移，滚轮缩放。
从地图上方「世界资料」进入。可为国家、城市、边界、地点和历史事件添加关联文档或独立画板，也可先创建资料再补链接。画板拥有各自的图层和年份，文档支持图文、表格、内部链接和独立导出。具体操作见[世界资料使用说明](WORLD_BOOK.md)。

新画板默认是 1600 × 1200 px 的白色平面画布，适合港口示意、交通简图和构图草稿。要使用地理投影或三维球体，请选择「新建地理地图」。现有地图画板继续按地理地图打开。

## 17. 外交关系

从「时间 → 外交关系…」记录双边关系或多边协约。可设置类型、参与国、起止年份、说明及关联事件。用「地图连线」查看当前年份的关系。关闭时间轴时可浏览全部历史关系。
