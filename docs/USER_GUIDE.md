# Atlas Forge 使用说明

Atlas Forge 是绘制架空世界与历史地图的桌面程序：在同一张地图上画陆地与国家，让国界、海岸、归属随年份变化，再导出成品地图。本说明介绍常用的做法；每个命令的说明也可在程序中按 **Ctrl+K**（命令面板）或 **F1**（快捷键一览）查看。

## 1. 安装与启动

- 解压 `AtlasForge-版本-windows-x64.zip`，双击 `atlas.exe` 即可运行，无需安装。
- 需要支持 DirectX 12、Vulkan 或 OpenGL 的显卡。无法启动时会弹出说明：更新显卡驱动；远程桌面或虚拟机中可能没有可用的图形设备；也可设置环境变量 `WGPU_BACKEND=dx12`（或 `vulkan`、`gl`）后再启动。
- 界面与导出的默认字体是随附的思源黑体开源版 Noto Sans SC（`fonts` 文件夹，SIL 开放字体许可）；缺少该文件夹时改用系统中的中文字体（微软雅黑、黑体等）。地图中的名称也可以选用系统里安装的任何字体。
- 检查程序是否正常：在命令行运行 `atlas.exe --self-test 某个文件夹`，会生成一个世界、做一次自动划分与道路、保存并读回、导出 PNG/SVG/PDF，报告写在该文件夹的 `自检报告.txt`。
- 用 `.atlas` 文件打开：把文件拖到 `atlas.exe` 上，或在命令行 `atlas.exe 世界.atlas`。

## 2. 界面

- **左侧工具栏**：选择、画陆地、扩张、夺取、挖湖、分配、切分、线路与河流、标注、符号、测量……；鼠标停在图标上显示名称与快捷键。
- **顶部选项栏**：当前工具的选项。
- **中间**：二维地图与三维球体（"视图"菜单可只看其一）。滚轮缩放，按住空格拖动平移（任何工具中都可用）。
- **右侧面板**：国家、数据表、字段、专题图、样式、图层、参考图等标签页；选中对象时显示其属性。
- **底部时间轴**：打开后地图显示所选年份，修改从该年起生效；关闭时显示最新状态。
- **状态栏**：坐标、比例、提示与撤销步数。

## 3. 从零开始：新世界向导

"文件 → 新世界向导…"：设定星球半径、陆地比例、大陆数、粗糙度、国家数、名称风格、河流数、是否放首都、是否生成一段随机历史，以及种子（同一种子得到同一个世界）。生成的大陆、国家、河流、地形都可以继续手工修改。

## 4. 画地图

- **画陆地 / 挖湖**：用多边形工具画出新的陆地或水域；与已有陆地重叠的部分自动合并。
- **扩张 / 夺取**：给所选国家画一块区域——扩张只占无主陆地与海，夺取连邻国的土地也一并取走。
- **分配**：点击地块把它分给所选国家。
- **填充桶**：把同一国家相连的一片地块整体改归属。
- **切分 / 合并**：沿一条线切开地块，或合并两个地块。
- **吸附**：画线时会吸附到已有的边、节点与参考线（按住 Ctrl 临时关闭）。
- **撤销 / 重做**：Ctrl+Z / Ctrl+Y；"历史"面板可跳回任意一步。

## 5. 年份与历史

- 打开时间轴（Ctrl+T），选择年份后再修改：修改只从该年起生效，更早的年份不变。
- 国家可设成立与终止年份、继承者；上级关系（省属于国家）也可随年份变化。
- **事件时间线**（"时间 → 事件时间线…"）：给一年或一段年份起名（战争、条约），在时间轴上显示，可导出编年表。
- **局部视图**：选一块区域和一段年份，独立查看那里的变化（不影响图层），可播放。
- **自定义纪年**：只改变年份的显示方式（如"开元 3 年"）。

## 6. 国家、地区与名称

- **自动划分**：选中国家 →属性面板"自动划分…"：划成几个新国家，或这个国家的下级地区（省）；可要求面积大致均衡、尽量沿河流与山脊；地图上预览，应用为一步撤销。国家里的湖泊和他国飞地不受影响。
- **名称生成器**（"工具 → 名称生成器…"）：按风格生成国名、城市名、山河名；国家与城市名称旁的"随机"按钮直接改名。
- **名称风格**：每个单位可设一种名称风格；文化等分区层中的单位设了风格后，位于其中的城市与国家随它起名。
- **自动配色**：相邻国家不同色，一键重配。

## 7. 分区层与数据

- 除政治层外，可建文化、宗教等分区层；比例层中每个地块可按百分比分属多个单位。
- 数据字段（人口等）可随年份变化，在"专题图"中做分级设色。
- 数据表可导入导出 CSV；也可导入 GeoJSON、Shapefile。

## 8. 线路、道路与旅行

- **线路**：画行军路线、商路、航线、铁路等；可设箭头、虚线、宽箭头、装饰（前线锯齿、铁路横线、山峰、树木）。
- **道路网**（"工具 → 道路与旅行…"）：在城市之间自动生成道路（绕开海与湖，陡坡代价更高），预览后应用为线路。
- **旅行**：在同一窗口选起点与终点城市，显示沿线路的路程与步行、车队、骑马、驿马所需天数；测量工具和所选线路也显示天数。

## 9. 外观

- **样式**："样式"标签页中可改海洋、陆地、边界、河流、标注的外观；**地图主题**（现代、古典图集、羊皮纸、深色）一键切换。
- **命名样式与色板**：线路、区域、文字、符号可共用命名样式，改样式即全部更新。
- **区域图案**：斜线、交叉线、点、山地、森林。
- **地形晕渲**：向导生成的地形可显示为晕渲，可调强度。
- **国名**沿国土弯曲并贴合球面；可用标注工具拖动到指定位置。

## 10. 导出与版式

- "文件 → 导出…"（Ctrl+E）：PNG、SVG、PDF、GeoJSON、Shapefile、CSV；可逐年导出、导出动画（需要 ffmpeg）、按版式导出地图集。
- **版式视图**（"文件 → 版式视图…"）：按导出的样子显示整页，拖动标题、图例、比例尺、指北针；添加插图框（显示另一区域的小地图），拖动或拖右下角改大小。位置随导出设置保存，也可存为版式。

## 11. 保存与恢复

- 工程文件扩展名为 `.atlas`。每次保存会把被替换的旧文件留作 `.atlas.bak1`（更早的为 `.bak2`、`.bak3`）。
- 程序意外退出后，下次启动会提示恢复未保存的工作。

## 12. 常用快捷键

| 操作 | 快捷键 |
|---|---|
| 命令面板 | Ctrl+K |
| 快捷键一览 | F1 |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y |
| 保存 / 另存为 | Ctrl+S / Ctrl+Shift+S |
| 导出 | Ctrl+E |
| 按年份查看 | Ctrl+T |
| 上一个 / 下一个变化年份 | PageUp / PageDown |
| 平移 | 按住空格拖动 |

## 13. 给脚本与 AI 用的接口

- `atlas-query.exe`：在命令行查询工程文件（国家、面积、年份变化等），输出 JSON。
- `atlas-mcp.exe`：MCP 服务器，供支持 MCP 的 AI 客户端读取地图。

## 14. 行星环境与气候

从「工具 → 行星环境与气候…」运行一次模拟，或开启实时更新。用「气候图」切换逐月参考层，「地表与修订」指定海拔、修改或固定区域，「方案与导出」比较方案并输出 PNG 或 CSV。操作示例、单位与分辨率见[气候使用说明](CLIMATE.md)。
