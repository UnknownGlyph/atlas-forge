# Atlas Forge 创作工作区

## 两套界面

点击顶栏的「创作工作室」或按 `Ctrl+Alt+F10` 进入工作室，再按同一快捷键切回。两套界面共用当前工程、年份、撤销记录和保存状态，各自保留地图视角。

- **开始创作。** 浮动工具条的「绘制」按地形、地点与标志组织常用任务。选择陆地、水域、河流、城市、文字、符号或像素画笔即可开始。「全部绘图工具」和顶栏「更多 → 所有命令」仍可调用完整工具。
- **管理画板。** 点「画板」直接切换已有画板、打开工程或新建空白画板。新画板立即进入编辑，可通过工程的撤销记录恢复。
- **在项目里查找。** 点「查找」或按 `Ctrl+F`，按名称搜索画板、文档和当前地图的城市、国家或地区。地图对象也可按编号搜索。用上下键移动到结果，按回车打开或定位。
- **控制地图。** 在「视角」中切换二维、球体或并排，缩放到全图或开启时间轴。「属性」按需展开。时间轴在「历史」页或已选择年份时出现，窗口较窄时较少使用的按钮收进「更多」。
- **材质与清晰度。** 工具条采样 GPU 绘制的低分辨率海陆底图，实时模糊、混合浅色材质。绘图文字和交互控件保持清晰。在「更多 → 减少透明度」可改为实色工具条，白纸画板默认使用实色。设置记在偏好中。

布局参考 Apple 建议的控制层与内容层分离，并给透明效果提供替代。工作室使用 Rust、egui 和 wgpu 实现。 [Apple 材质指南](https://developer.apple.com/design/human-interface-guidelines/materials)


## 世界观设定

在专业界面的「视图 → 世界观设定」或工作室的「世界观」页面开始。

1. 新建实体类型，例如家族、城市或文明。也可从「从内置模板开始」安装家族与谱系、人物关系网或国家矿产档案。为类型添加文本、数值、布尔或实体引用属性。属性的标识用于公式，显示名称可单独修改。
2. 新建实体记录，填写分类、标签和有效年份。勾选「编辑指定年份」可记录随时间变化的属性。基础值用于更加通用的设定。锁定属性可固定某个值。
3. 新建关系类型，选择是否限制两端的实体类型。然后创建关系实例并填写两端实体和生效时段。
4. 在记录中关联当前地图选择，或通过「查看或编辑全部关联」连接已有事件、文档、图片、画板和其他对象。文档编辑器可插入指向设定记录的内部链接。编辑关系和属性后，点击「保存修改」写入工程。
5. 把常用记录保存为模板。之后可新建多条相同类型的记录，每条均可独立修改。

数值属性可指定公式，例如 `人口 / map_area`。内置变量包括 `year` 和 `map_area`。可添加自定义变量，从关联地图字段、关系两端属性、关联数量或环境图层读取数据。指定年份时，显示标题标明解读所用的时间轴年份。环境引用使用生成的当前方案，切换查看用的历史方案不改变资料的计算源。

在世界资料库中选中文档、事件、地点、附件或独立画板，可用「删除此项」或 Delete 打开删除确认。修改加入项目撤销历史和自动保存。对世界观、图表、外交记录、环境版本和局部视图使用 Delete 时，按当前选中项目操作。光标在文本框内时，Delete 用于编辑文字。

## 环境生成

专业界面从「工具 → 环境生成与图层」进入。工作室的「环境」页面在地图右侧提供生成面板。选择全球、当前局部视图或自定范围，指定网格长边、地形种子、起伏、海平面阈值、降水倍率和环境参数。配置数字联动时，可从世界观记录中选择一个数值属性用于某个参数。

「保存参数」后点击「生成图层」。也可开启自动生成，让相关地图、年份或设定改动后在后台重算。手动方式保留上一版，便于连续绘制地图。已绘海陆、湖泊、地形图、山脉、森林、河流和行星气候参数会进入计算。可选择是否生成尚未指定的地表。

生成结果包括海拔、坡度、地形分类、集水面积、河网流量、气候、土壤湿润度、植被、生态和生物多样性。资源和物种适宜性可由公式另行定义。例如用 `vegetation * (1 - min(1, abs(temperature - 13) / 26)) * land` 表示特定温带动物的广域栖息适宜性。

在「图层与版本」中切换显示、另存方案，或导出 PNG。地图导出也可包含当前叠加层。在「局部修改」中点击地图或球体取样，设置修改幅度和格数。可写入数值、冻结当前值或撤回局部修改。较粗的历史气候网格用于计算大气背景，局部高程与精细海陆条件用于细化区域结果。输出适合世界构建时比较条件和寻找空间规律。

依赖顺序是地图与历史数据、上游设定、环境生成、环境统计与可视化。计算环境参数时，如果公式又读取环境输出，界面会提示循环依赖并保留上一版结果。

## 数据可视化

在「视图 → 数据可视化」或工作室的「图表」页面新建图表。数据可来自地图字段、世界观属性、指定记录的时间序列、世界观关系、导入表格或手工录入。剖面沿大圆路径对高程图或环境图层采样。

可切换统计柱状图、曲线、散点、关系网络、环境剖面、地图图标或专题地图。调整转换公式、色带、颜色范围、分级阈值和图标样式后保存。专题地图和地图图标可直接叠加在 2D 地图与球体上。CSV 可选择名称、横轴、数值和经纬度列，也可指定例如 `atlas-entity:0/12` 的项目链接。图表数据可导出为 CSV。

## 涂色与脚本步骤

选择绘制陆地或水域工具，依次启用「涂抹」和「涂色模式」。选好颜色后可在图上涂抹。每个笔触作为独立的实色区域进入当前要素图层，可通过图层面板选择、修改或删除。

「工具 → 脚本可视步骤」可用当前工程运行 JSON 自动化脚本。窗口显示原始地图和每个成功步骤，支持正向播放、单步查看和拖动进度。脚本全部成功后可采用最终工程，形成一次撤销操作。脚本中途失败时会标出失败步骤。

## 时间播放与视频

在「时间 → 时间播放与视频」设置起止年份、自定义采样间隔、总时长与播放速度。可按地图、事件、资料和属性有记录的年份播放，或固定间隔采样。开启循环可持续预览。局部视图内可选择使用其地理范围与对应年份。选择「导出 MP4」时，程序通过系统中已安装、可从命令行调用的 FFmpeg 进行 H.264 编码。

## 文件位置与测试工程

「设置 → 文件与缓存」可修改文件对话框的默认保存目录、崩溃恢复与缓存位置、默认测试工程。缓存位置在下次启动生效，包含崩溃报告、恢复副本和未命名工程版本。打开测试世界时会读取本地伊瑟尔三国工程的可编辑副本。若软件找不到工程文件，第一次打开可在文件对话框指定。

## 星图与保存设置

在星图的真实恒星视图中，可以切换「太阳系中心」或「银河系中心」。数据表的坐标原点会随之变化；相对太阳的距离仍使用同一口径。两种坐标可以分别导出 CSV。

在「设置 → 保存与云同步」可分别选择 OneDrive 和坚果云客户端的本地同步目录。自动保存会把独立的工程版本写入所选目录的 `Atlas Forge Backups` 下。Atlas Forge 报告本机写入状态，桌面同步客户端负责将副本同步到账号。两家服务的配置分别生效。本地工程、项目历史和存档仍可离线打开。

[OneDrive 官方同步文档](https://support.microsoft.com/en-us/onedrive/sync-your-computer-s-files-and-folders-with-onedrive) · [坚果云官方同步帮助](https://help.jianguoyun.com/?p=416)
