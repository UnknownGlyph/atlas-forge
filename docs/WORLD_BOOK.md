# 世界资料

在地图上方打开「世界资料」，或从「视图」菜单打开。这里集中浏览画板、文档、事件、图片和附件。可以直接创建任意一种内容，也可以先在地图上选择对象再建立关联。列表支持按名称、分类和标签搜索。关闭「按当前年份筛选」可以查看其他时期的条目。

## 从地图对象开始

1. 选择国家、行政区、城市、地块或绘制要素后打开「世界资料」。也可以点「地图取对象…」并在地图上点击。
2. 在详情的「地图取点」菜单选择「地块」「边界」或「放置资料地点」，可将文档与具体的区域、边线或坐标关联。
3. 点「新建关联文档」或「新建关联画板」，也可以从「选择关联对象」中选择已有资料并保存链接。
4. 用选择工具点击有关联的地图对象或资料地点可以查看资料。双击有唯一目标画板的对象可直接进入那张画板。事件资料也可以通过时间轴标记进入。

链接保存的是工程内的对象标识。对象更名、切换年份和重新打开工程后，链接仍然可用。部分地块或边界被重建时，会尝试根据原位置找回对应要素。彻底删除对象后，相关链接仍可在资料中修改或解除。

## 管理文档、图片和事件

- 「新文档」创建独立文档。进入编辑模式后，使用标题、强调、列表、表格和链接等工具，或直接写 Markdown。切换到阅读模式即可预览排版。
- 「插入图片或附件…」把本地文件保存进工程。「插入当前画板截图」把当前画板的渲染图插入文档。可在「图片与附件」中独立预览、重命名和导出文件。
- 从编辑工具栏的「内部链接」选择文档、事件、画板或已有图片附件。阅读时可点击跳转，使用「返回资料」回到上一条资料。链接使用稳定的工程内地址，例如 `atlas-doc:12` 和 `atlas-map:27`。
- 「新事件」把事件添加到当前画板的时间轴。可以编辑起止年份、分类、标签和说明，并把同一事件关联到多个地点、文档或不同阶段的画板。详情中的「在当前地图标记事件…」可放置多个地图标记，「查看事件起始年」可切换到该事件发生时的地图。

## 创建并浏览独立画板

- 「新画板」创建 1600 × 1200 px 的白色平面画布，适合示意图、版面草稿和专题图。使用像素坐标与现有矢量工具。选择「新建地理地图」可获得地理投影、球体和气候工具。「复制画板」可由已有画布创建新版本。
- 层级链接允许同一画板有多个入口，也可以从顶层地图直接连到深层画板。交叉链接可连接同级或其他层级，用于从一个专题跳到另一个专题。
- 地图上方显示导航路径，可点击其中任意一层或使用「返回上层」。画板详情也显示来自上下层和其他资料的链接。现有链接可修改起点、终点、名称和时间。
- 目标画板的时间规则可设为保留自己的年份、跟随来源年份或跳到指定年份。也可以设置链接生效的年份区间，在不同时间展示不同入口。
- 解除链接只删除关系。独立画板和文档仍可通过资料库找到。需要删除某个条目时，可在其详情中确认删除；共享资料与其他画板保留。
- 通过「保存工程」将世界地图、其他画板、链接、事件、文档和附件保存到同一个 `.atlas` 文件。带平面画布或外交关系的工程使用格式 6，本版仍可读取旧工程。「另存画板」可把选中的画布单独另存为一份 `.atlas`。

## 导出

- 在文档详情选择 TXT、Markdown、DOCX、PDF 或 HTML，再点「导出文档」。在资料列表勾选多篇可以逐篇导出，也可按一份资料集合并导出。
- 可选择附加关联事件、地图截图和附件目录。文中明确插入的图片随支持图片的格式导出。TXT 中显示图片说明。Markdown 的图片与附件放在同名的 `.assets` 目录，搬移时请一起复制。HTML 将图片与附件嵌入文件。DOCX 和 PDF 中的普通附件可用「附件单独导出」获取原文件。
- 合并后的 HTML 和 DOCX 中，指向同次导出文档的内部链接可在文件内跳转。原工程和其他画板的内部链接可在 Atlas Forge 中使用。PDF 的正文沿用矢量文字轮廓，适合阅读和打印。
- 画板可导出 PNG、SVG、PDF、GeoJSON、Shapefile 或 CSV。使用「导出下属画板」一次导出整个分支，共享画板只导出一次。「画板和资料一起导出」会同时生成子目录内的地图与可查阅的关联资料。
