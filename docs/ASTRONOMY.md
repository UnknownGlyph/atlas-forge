# 星图与模型

在「星图」中切换本恒星系、地月系和银河系。先选中天体，再改名称、轨道或质量。使用「应用到工程」保存配置。

- **本恒星系** 可添加两颗伴星，组成双恒星或三恒星系统。也可以新增自定义天体，给它设类型、质量、半径、自转、轨道和模型。
- **地月系** 可继续添加自然卫星或人造天体。新增模型后可以随轨道查看，也可以在独立查看器中放大。
- **相互引力** 开启时保留当前轨道相位。程序按实际质量、半长轴和偏心率建立初速度，计算主体行星与卫星共同质心的运动。太阳、行星、卫星与伴星都会参与相互摄动。关闭时按面板设定的公转周期播放示意轨道。
- **轨道方向与扁率** 可设置升交点黄经和近心点幅角。局部系统的主体星球 J₂ 可用于计算扁率对低轨卫星和轨道面的影响，地球参考值为 0.00108263。选中一颗天体可读取它相对中心天体的当前距离、速度和瞬时轨道要素。
- **摄动对照** 开启引力后，选中新增的行星、伴星或卫星，设置对照时长并运行「对照有无所选天体」。两次计算从其他天体完全相同的当前状态出发，比较最后共同历元的位置偏移、偏心率变化和近心距变化。行星以主恒星为参考，卫星以主体星球为参考。计算可取消并在后台运行。
- **银河系** 展示棒旋星盘示意和 8,000 条 Gaia DR3 真实观测记录。可分别以太阳系和银河系为坐标原点观察并导出 CSV。点选可查看源编号、银经、银纬、距离、星等和当前坐标。自定义星体支持三维坐标和模型。署名为 ESA/Gaia/DPAC。[数据选取及引用](https://github.com/UnknownGlyph/atlas-forge/blob/main/assets/astronomy/README.md)

在世界资料库选择画板、文档或地图对象，点击「导入 3D 模型」会把模型保存为当前工程的附件，并关联到选中的对象。打开关联链接即可单独查看。模型文件包括 OBJ、GLB 及几何缓冲区自包含的 glTF。查看器显示静态网格、材质基色及线框，支持任意旋转、平移和缩放。多体系统配置与天体模型引用使用 Atlas 工程格式 7。


多体推进采用自适应 Dormand–Prince RK5(4)，在近距离相遇时缩短时间步。遇到物理接触时暂停并标出天体。达到播放计算开销上限时，模拟时钟会放慢。地月画面仍使用示意比例，实际距离以读数为准。这个模型适用于架空系统的轨道与摄动探索。潮汐耗散、广义相对论、天体形变及碰撞后的演化留给更专门的数值模型。默认模板参数与算法参考 [JPL 天体动力学参数](https://ssd.jpl.nasa.gov/astro_par.html)、[NASA 月球资料](https://nssdc.gsfc.nasa.gov/planetary/factsheet/moonfact.html) 和 [Dormand 与 Prince 的原始论文](https://doi.org/10.1016/0771-050X(80)90013-3)。

新设定的轨道方向和 J₂ 会保存到格式 10，仍可打开此前的工程。
