# 行星环境与气候

在 **工具 → 行星环境与气候…** 打开面板。新工程默认使用手动模式。选好年份后按 **运行模拟**，即可在当前地图上查看气候，包括完全空白的工程。关闭面板后仍可绘图，通过「显示图层」和透明度控制参考图。二维投影与三维球体共用同一份结果。

## 从空白世界开始

1. 使用「标准地球」模板运行一次。在「气候图」内切换温度、降水、相对湿度、风和水汽输送方向、冰雪、年温差、气候类型、植被适宜性或干湿指数。月份为公转周期的十二等分，季节按 12–2、3–5、6–8、9–11 月分组。降水取所选时段的累计毫米数，风向为自北顺时针的**吹向**。
2. 绘制大陆、湖泊、河流或山地区域。手动模式保留上次结果；实时模式在编辑稍停后后台计算，切换地图年份也会更新。地图点选只在按下「从地图取点」后接管一次单击。
3. 在「地表与修订」选择点位和笔刷半径，使用「添加地表资料 / 绘制高原」写入局部海拔、冰原、森林或水体。半径以行星表面的圆心角表示；半径为零选中一个网格。这些资料与原图的国界、归属、地形分别保存。
4. 在「模拟范围」可输入西、东、南、北边界，或到地图上点两个角。西界大于东界表示跨日界线。局部统计按面积加权，范围外的结果透明；计算水汽来源时仍考虑上风方向的地理。
5. 在「方案与导出」为当前结果命名并留存，再修改行星或地理条件。点选留存方案可切换参考图，相同范围的方案还会显示与当前结果的均温和降水差。可导出全球等距经纬 PNG 或区域逐月 CSV。保存工程会同时保存参数、结果和修订。自定义参数模板可另存为 JSON 后在其他工程载入。

## 行星与约束

可见的参考图也会随普通成图导出到 PNG、SVG 和 PDF。气候数据需要支持格式 2 或更新格式的应用。工程若同时保存了自定义星图，需要支持格式 3。

行星半径在首次启用时取自地图；之后作为独立模拟条件，便于在同一张地图上比较不同大小的行星。恒星类型可从光谱模板选择，或直接调恒星温度。参数编辑器提供手动、固定、自动三种状态。手动输入数值会将该量设为手动。固定量需先解锁才能编辑。只有自动量参与物理方程求解或目标搜索。

- 要保留地球重力，可载入「地球重力」，再调半径。半径设为 1.5 倍地球时，联动得到 2.25 倍地球质量。
- 要保留地球辐照，将辐照固定为 1361 W/m²，保持距离为自动，输入恒星光度。4 倍太阳光度对应 2 AU。
- 在「反向搜索气候目标」里选均温、年降水、冰雪比例、干旱及半干旱比例或年温差。搜索仅调整自动量，用所选地理和同一套逐月模型评价候选组合。可实现的精度受地理、锁定条件和搜索范围影响。「地球气候」中的比例和季节目标是创作参考值。
- 物理关系矛盾时，面板提示条件冲突并保留已有结果。可改变参数控制方式，或关闭物理联动，使用自行设定的组合。地图编辑始终可用。

## 人工修订

在气候图中选一个量和时段，再在「地表与修订」写入新数值。年或季降水写入值平均分配到相应月份。「固定当前值」保存这个量的逐月曲线，「固定所有气候量」保留所选网格的全部参考量。未固定的修订在下次计算时更新。「恢复自然值」移除当前量的人工和固定记录。数据面板及 CSV 记录人工与固定标记，留存方案保存创建时的数据。修改可通过普通撤销恢复。

## 模型与尺度

- **日照与温度。** 逐月求解椭圆轨道位置与恒星赤纬，普通自转使用日平均入射角，同步自转使用经纬度相对星下点的入射角。吸收辐射、有效反照率、温室参数和水平热输送决定平衡温度；一阶热库把陆地和水体转化为不同的季节温差与滞后。海拔按重力修正直减率降温。日平均辐射几何的推导见 [The Climate Laboratory](https://brian-rose.github.io/ClimateLaboratoryBook/courseware/insolation/)。
- **水汽与地形。** 诊断风场随自转方向、速度、季节和潮汐锁定而变。逐格沿上风向采样陆地、水体、河流及地形，估算水汽供给、抬升降水与雨影，再从逐月水热条件计算干湿和宽泛的气候、植被类型。冰雪对反照率及温度有简化反馈。
- **地理资料。** 海陆取选定年份；有高程栅格时采样实际高度。山区图案、森林图案、山峰、火山和河线可提供额外线索。缺乏实测高程的山区和峰点分别使用 1800 m、2600 m 的示意高度，可用地表笔刷替换。普通未绘背景保持「未指定」，采用空间均匀的水体比例先验。向导世界的已有地形和明确的陆地背景提供已知地表。
- **有效分辨率。** 当前为 96 × 48 等经纬网格，每格 3.75°。PNG 放大到 768 × 384，连续量插值，气候类型与植被保留类别边界。小于网格的岛屿、山谷与湖泊可能无法分辨。风、湿度、降水与植被为创作估算；模型未求解三维海洋环流、逐日天气或物种分布。
