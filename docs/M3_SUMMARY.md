## 1. 结论

M3 的目标是“同一份地图能正确表达任意年份的状态”。核心规则（ADR-7，产品方确认）：**修改某一年之后的地图，不得改变更早年份的地图**。目前这条规则覆盖了归属、上级关系、多个分区层、比例分布和海陆（海岸线），并由随机化测试持续检验。

| 自动化测试 | 97 个（M2 结束时约 50 个），全部通过 |
| Rust 代码 | 约 16,000 行（5 个 crate） |
| M3 相关提交 | 13 个（`09c5cd3` … `030d37b`），另含 M2 收尾的局部重建、参考图、背景面 |

## 2. 已完成的功能

### 2.1 时间模型（所有随年份变化的内容用同一种表示）
每项数据 = **起初的值 + 年份变化点**（“从该年起为 X，直到下一个变化点”）。所选年份的状态是派生出来的视图，渲染、专题图、统计、标注和导出都只读这个视图，因此几乎不需要为时间改动这些模块。

| 随年份变化的内容 | 存储 | 派生视图 |
|---|---|---|
| 地块归属 | `owner_base` + `owner_changes` | `Document::owner` |
| 上级关系（省属哪国） | `Entity::parent_base` + `parent_changes` | `Entity::parent` |
| 其他分区层（实际控制等） | 每层一份同样的归属存储 | 切换当前层时交换 |
| 比例层（文化、宗教） | 每块地各单位万分比 + 变化点 | 取最大者作为归属 |
| 海陆（海岸线） | `kind_base` + `kind_changes` | 拓扑中的 `kind` |

**编辑规则**（对以上各项一致）：
- 选了年份：只在该年加变化点，更早年份不变；与当时值相同的冗余变化点自动去掉。
- 未选年份：修改所有年份；对象已有历史时**拒绝**（避免无意中抹掉历史）。
- 几何操作与历史：切分对所有年份生效，两半继承相同历史；合并要求所有层、所有年份的历史都相同；绘制产生的新面继承来源面的全部历史，再只在所选年份记录新状态。
- 旧工程文件原样可读（旧字段即“起初的值”）。

### 2.2 功能清单
1. **归属随时间变化**：时间轴（滑块、年份输入、跳到上/下一变化年份），地块与国家的变化年份可点击跳转。
2. **上级关系随时间变化**：省从某年起改属另一国；在该年及之后所有变化年份检查环路。
3. **多个分区层**：政治层之外可建任意独占层；单位、合并、嵌套只在同层内。
4. **两层同时显示**：当前层填色，另一层以彩色边界线叠加（如政治填色 + 实际控制线），屏幕与导出一致。
5. **比例层**：一块地按比例分属多个单位；颜色按比例混合，面积按比例计入，画笔带比例。
6. **逐年导出**：每年一个文件（PNG/SVG/GeoJSON/CSV），并行渲染、可取消；标题模板 `{year}`。
7. **动画导出**：GIF；装有 ffmpeg 时可导出 MP4（H.264）。
8. **数据的年份语义**（ADR-7，产品方给出原则）：基础值独立于年份；每字段可选“严格年份 / 最近历史值 / 基础值回退 / 线性插值”，默认数值严格、文本等静态属性回退；基础值可设“生效年份”；每个值都带来源（记录、基础值、沿用、插值、计算、未知），界面和导出保留来源。
9. **统计口径**（ADR-7，产品方选择）：由面积计算的值使用其数据所属年份的边界（沿用 1900 年人口时除以 1900 年面积），插值与无年份基础值用所选年份边界，不同年份的输入标为“混合口径”。
10. **海岸线随时间变化**：几何共用，海陆随年份变化；选了年份画的岛/湖从该年出现；地块可“从该年起变为水域/陆地”；水域年份无归属但其他年份归属保留。

### 2.3 M2 收尾（同期完成）
- 在已有陆地上绘制改为**局部重建**：4000 国时 504 ms → 62 ms；顺带修复球面面积公式在近水平线段上的数值相消（单边误差约 0.35 km²）。
- **参考图**：PNG/JPEG/TIFF/WebP/BMP，按像素逐点反投影显示（任意投影与球体下按同一配准模型一致显示），拖动配准（1 点平移 / 2 点相似 / 3+ 点仿射），残差与投影排名。
- **背景面与“海洋”分离**：背景可设为陆地（全陆地星球），海陆只由 `kind` 决定。

## 3. 如何验证的

- **关键不变量的随机化测试**（每条都做过“故意破坏实现 → 测试失败”的反向检查）：
  - 60 步随机编辑（领土画笔、夺取、扩张，局部与整体两条路径）在随机年份进行，每步后所有更早年份各国面积与编辑前完全相同。
  - 80 步随机上级修改（含被拒绝的环路），每步后更早年份“面 → 顶层国家”映射不变。
  - 在文化层编辑几何后政治层各国面积不变；跨海岸绘制和开凿海湾后更早年份的陆地面积与各国面积不变。
- **语义测试**：每种继承策略与来源（含“零 ≠ 未知”）、统计口径的各种情形、比例重分配、存盘往返、旧文件读取。
- **界面验证**（在应用中实际操作）：时间轴划拨与回看、上级变化后边界线类型变化、两层叠加线、比例层混色与面积、逐年 PNG、MP4/GIF（抽帧核对两年画面与标题）、数据表来源提示与“*”口径标记、海中造岛与国家被淹没后回看。
- 界面验证中发现并修复的问题：陆地背景下跨反经线的多块面类型错位（已加回归测试）、批量导出无法在原生文件夹对话框中输入路径（改为导出窗口内的文件夹输入框）、◀▶ 字形在中文字体中缺失。

## 4. 性能（Release，本机）

| 操作 | 40 国 | 240 国 | 1000 国 | 4000 国 |
|---|---|---|---|---|
| 在陆地上绘制（局部重建） | 1.6 ms | 4.7 ms | 12 ms | 64 ms |
| 同上，整体重建（选了年份时走这条） | 7 ms | 30 ms | 116 ms | 517 ms |

历史记录对局部绘制的额外开销 < 5%（62 → 64 ms）。逐年导出：2 张 3000×1600 PNG 约 0.1 s；1280×720 MP4 两年约 0.9 s。

## 5. 已知限制与未验证内容

**设计上的取舍**
- 选了年份时跨边界绘制总走整体重建（大图约 0.5 s）；局部拼接尚不支持历史继承。
- 海岸线变化以“细分 + 海陆随年份”表达：要表现海岸线逐渐推移，需先画出各阶段的区域；没有几何插值，动画中海岸是逐年跳变。
- 实体（国家）本身没有存续年份：没有领土的年份它仍在国家列表中（图例只列有领土的）；名称、颜色不随年份变化（按产品原则属静态属性）。
- 背景面的海陆是固定设置，不随年份变化。
- 比例层上的“夺取”使单位获得该区域 100%；“扩张”沿用“只占无主地”的判断（以最大比例者为准），语义较粗。
- 年份切换不进入撤销历史；但撤销会回到快照当时的年份。

**未测量 / 未验证**
- 大量历史记录（如数千个变化点）下拖动时间轴的帧时间未测；数据表每帧为“其他年份面积”重算一次（按年缓存于一帧内），大图下的开销未测。
- 上级环路检查的复杂度约为 O(实体² × 变化年份数)，大规模层级未测。
- GIF 每帧 256 色量化，渐变/混色明显时有色带；MP4 依赖用户自行安装的 ffmpeg。
- 仅在 Windows 11 上验证。

**M2 遗留**：超大参考图分块显示（目前缩小到显卡纹理上限）、参考图不进入导出、Shapefile 等格式（GDAL/PROJ）。

## 6. 希望评审的问题

1. 时间模型统一为“起初值 + 变化点”，并把“所选年份视图”作为派生数据——这种方式在更复杂的历史场景（如同一年内多次变化、日期精度、不确定年代“约 1900 年”）下是否会成为瓶颈？
2. 海岸线用“细分 + 海陆随年份”而不是“几何多版本”：对于河口淤积、填海等需要连续变化的场景，是否足够？是否值得引入几何版本？
3. 是否需要“实体存续年份”（建国/灭亡），以及没有领土的年份实体应如何在列表、图例、数据表中呈现？
4. 数值字段默认“严格年份”（缺记录即未知）是否对普通用户过于严格？是否应在首次使用时引导设置？
5. 比例层与绘制工具的交互（夺取 = 100%）是否符合直觉，还是应让绘制在比例层中也使用画笔比例？
6. 下一阶段的优先级建议：性能（时间轴、超大图）、数据互通（GDAL/Shapefile）、还是成图版式（标注编辑、版面）？
