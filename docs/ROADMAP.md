# Atlas Forge 整体规划与路线图

> 2026-11-10 制定，基于提交 `c12acf0` 的实测审计。本文只做规划，不含功能改动。
> 细节设计仍以 `ARCHITECTURE.md` 为准；本文回答"接下来做什么、按什么顺序、做到什么算完成"。

## 0. 一页摘要

**定位**：用专业绘图软件的手感，创作带历史的架空世界地图。

**现状判断**：内核（球面拓扑、逐年历史、数据与专题、导出、性能）已经扎实，百万三角形下每帧约 8 ms；但外壳还是"工程师界面"——文字工具列表、三个菜单、没有右键菜单与图标、每类对象只能选一个。与专业绘图软件的差距几乎全部在交互外壳、样式系统和制图表现上，而不在内核。

**路线**（按依赖顺序，不承诺日期）：

| 里程碑 | 主题 | 一句话目标 |
|---|---|---|
| M6 | 稳固与手感 | 修掉已定位缺陷，建立专业软件的交互骨架（动作层、多选、右键、首选项、图标工具栏） |
| M7 | 专业编辑 | 图层面板、变换与对齐、曲线、样式系统、字体 |
| M8 | 制图表现 | 地图主题、地形晕渲、标注引擎、所见即所得的版式视图、PDF |
| M9 | 架空世界工具箱 | 新世界向导、大陆与河流生成、自动划分、名称生成、自定义历法、事件时间线 |
| M10 | 跨平台与发布 | Linux / macOS、安装包、内置字体、中英文界面、用户手册 |
| M11 | AI 共同创作 | AI 阶段 C–D：草稿、预览、提交；可与 M7–M9 并行 |

**最先做的十件事**（都属于 M6，前三件已定位到具体代码）：

1. 修复两处归属视图缺陷，并把随机压力测试正式入库（补丁已验证，见 §6）。
2. 改为按需重绘：空闲 CPU 实测可从单核 21% 降到约 2%。
3. 崩溃钩子：崩溃时写日志并紧急保存恢复文件。
4. 持续集成：Windows 跑测试与 clippy，Linux / macOS 先做到能编译。
5. 动作层：所有操作登记为"动作"，菜单、快捷键、右键菜单、命令面板共用一张表。
6. 统一选择模型与多选（Shift 加选、框选）。
7. 首选项文件（界面缩放、主题、自动保存间隔）、最近文件、欢迎页。
8. 图标工具栏、上下文选项栏、状态栏整理。
9. 支持包围极点的陆地（现在无法绘制极地大陆）。
10. 旧版工程文件的兼容性样本测试。

**进度（2026-11-11）**：第 1–7 件与第 10 件已完成（见 `ARCHITECTURE.md` M6 第一至六步）；第 8 件（图标工具栏、选项栏、状态栏）与第 9 件（包围极点的陆地）也已完成（M6 第七、八步），前十件事至此全部做完。持续集成的配置已写好但仓库没有远程，尚未运行。M7 已开始：要素的多选、剪贴板、旋转缩放、对齐分布、锁定、历史面板、图层面板（M7 第三步）、曲线和钢笔工具（M7 第四步）、样式系统（M7 第五步：命名样式、色板、吸管、图像回归测试）与字体（M7 第六步）已完成；参考线与智能吸附未做，分区层与参考图尚未并入图层面板的同一个栈。接手开发请先读 `HANDOVER.md`。

## 1. 产品定位与原则

### 1.1 三个支柱

| 支柱 | 含义 | 参照 |
|---|---|---|
| 专业绘图体验 | 工具、选择、图层、样式、排版的手感与效率 | Illustrator 为主，Photoshop 的图层与历史面板为辅 |
| 架空世界创作 | 从空白到一个可信世界的便利：生成、划分、命名、纪年、叙事 | Wonderdraft、Inkarnate、Azgaar's Fantasy Map Generator |
| 可信的历史与数据 | 逐年变化不互相覆盖、统计口径清楚、结果可验证 | 现有内核（ADR-7、存续期、统计口径） |

AI 共同创作是贯穿三者的第四条线：AI 与人共用同一套操作，见 §4.10。

### 1.2 与同类的区别

| | 专业绘图软件 | 幻想地图工具 | GIS | Atlas Forge |
|---|---|---|---|---|
| 几何 | 平面矢量 | 平面图片或矢量 | 真实坐标 | 球面拓扑，二维多投影与三维球体同源 |
| 相邻边界 | 各画各的 | 各画各的 | 需要拓扑规则 | 共享边界，天然无缝 |
| 历史 | 无 | 少数有 | 需自建 | 逐年归属、海陆、隶属、存续 |
| 数据与专题图 | 无 | 少 | 强 | 字段、继承策略、分级设色、统一分级 |
| 绘图手感 | 强 | 中 | 弱 | **目前弱，本规划的重点** |
| 生成与便利 | 无 | 强 | 无 | **目前无，M9 的重点** |

结论：不与专业绘图软件比通用绘图，也不与幻想地图工具比贴图素材量；要做的是把它们的手感与便利，装到我们独有的内核上。

### 1.3 原则（延续）

- 离线可用；内核不依赖网络与模型服务。
- 矢量与拓扑为本；图片只作参考图与（将来的）地形栅格。
- 历史保护：较晚年份的编辑不改变较早年份；无年份地图行为不变；旧工程可读。
- 不为增加配置而让普通操作变复杂：新能力默认有合理取值，高级选项收起。
- 结论以实测为准：性能看基准，正确性看测试，界面看实际运行。
- 编辑逻辑写在 `map_core`，界面只收集输入并调用（AI 阶段 A 约束）。

### 1.4 明确不做

- 不做通用位图编辑（滤镜、修图）；不做通用矢量插画。
- 不做在线协作服务器、账号体系、云存储。
- 不追求完整 GIS（坐标系转换库、空间分析工具箱）；互通以交换格式为限。
- 不内置联网的素材商店或模型服务。

## 4. 规划主题

每项标注优先级：P0 必须先做，P1 应当做，P2 视反馈再定。

### 4.1 交互骨架（M6）

目标：操作方式与专业软件一致，新功能有统一的"挂载点"。

- P0 **动作层**：每个操作登记名称、图标、快捷键、可用条件与执行函数。菜单、工具栏、右键菜单、快捷键表、命令面板都从这张表生成。这同时是 AI 阶段 C 的写操作目录，一次建设两处受益。
- P0 **统一选择模型**：一个选择集可同时包含国家、地块、线、文字、符号、区域；Shift 加选、Ctrl 减选、框选；选择集驱动属性面板与右键菜单。
- P0 **菜单补全**：文件、编辑、选择、对象、视图、图层、时间、窗口、帮助；每个工具与操作都能在菜单里找到。
- P0 **右键菜单**：画布（按所指对象）、列表项、时间轴。右键拖动仍为平移。
- P1 **命令面板**（Ctrl+K）：按名称搜索并执行任意动作。
- P1 **首选项**：界面缩放、主题、自动保存间隔、默认投影、语言；保存在用户目录。
- P1 **最近文件与欢迎页**：新建（空白、示例、向导）、最近工程、恢复未保存的工作。
- P1 **导航**：空格拖动平移、缩放到所选、缩放比例显示、双击缩放。
- P2 快捷键自定义；多文档标签页；可停靠面板布局。

完成判据：任何操作都能通过菜单、快捷键、右键三种方式之一在两步内到达；多选后可批量移动、删除、改样式。

### 4.2 绘图与编辑工具（M7）

- P0 **图层面板**：版面要素（河流、线路、符号、区域、文字、参考图）可分组、排序、锁定、调不透明度；分区层在同一面板中切换与叠加。
- P0 **变换**：对所选要素数值移动、旋转、缩放（球面上保持真实大小，沿用 `copy::moved` 的旋转思路）；对齐与分布。
- P0 **剪贴板**：复制、剪切、粘贴，可跨年份与跨工程。
- P1 **曲线**：线与区域支持曲线段与手柄；存储为带曲线标记的点列，渲染与导出时细分，拓扑边界仍为折线。
- P1 **历史面板**：列出每一步，可点选回到任一步。
- P1 **参考线与智能对齐**：对齐到经纬线、其他要素的端点与中线（已有，M7 第九步：拖动要素时吸附并显示参考线）。
- P1 **填充桶**：点击即把一片连通的无主地或所选范围归属给当前国家（已有，M7 第九步）。
- P1 **按属性选择**：按种类、图例说明、年份范围、字段值（已有，M7 第九步；字段值待国家进入统一选择）。
- P2 套索选择；隔离编辑；数位板压感（先评估 winit 的支持情况）。

完成判据：用图层、多选、变换与对齐，可在不逐个调整的前提下整理一幅有上百个要素的地图。

### 4.3 样式、文字与制图表现（M7–M8）

- P0 **样式系统**：描边、填充、图案、文字各有命名的样式；要素引用样式，改样式即全部更新；色板与吸管。旧工程中的逐要素设置自动成为"本地样式"，行为不变。
- P0 **字体**：可选字体与字重；内置一套开放许可的中文与西文字体，保证各平台与导出一致。应用内与导出改用同一套文字排版，消除两者的布局差异（现在导出用估算的字宽）。
- P1 **地图主题**：一键切换整套样式（现代、古典图集、羊皮纸、深色）；主题只是样式集合。
- P1 **海岸与水域效果**：海岸线晕线、水域渐变、内发光。
- P1 **地形**：高程栅格层与晕渲；山脉、森林等面状符号填充与沿线散布笔刷。
- P1 **标注引擎**：国家名称沿形状主轴弯曲并自动调字距（已有，M7 第七步：应用内与导出共用 `LabelPath`，球面上贴合曲面）；优先级与避让统一（未做）。
- P1 **版式视图**：在画布上直接摆放标题、图例、比例尺、指北针、插图框；所见即所得。应用内显示比例尺与指北针。
- P1 **PDF 导出**与按纸张尺寸、DPI 导出。
- P2 多重描边（国界的双线、内侧色带）；标注的首字下沉与装饰；色盲友好色带检查。

完成判据：同一工程切换主题后可直接导出风格完整的成品；应用内看到的文字位置与导出一致。

状态（2026-11-16）：样式系统、字体、四套地图主题、海岸晕带、地形晕渲、PDF 导出、应用内的比例尺与指北针、导出范围预览已完成；可拖放的版式视图（含插图框）已完成（2026-11-16）；山脉与森林的区域图案与沿线装饰已完成；标注避让在应用内与导出中各自统一（两者之间不保证逐一相同）。

### 4.4 架空世界创作便利（M9）

- P0 **新世界向导**：星球半径、海陆比例、大陆数量与破碎度、种子；生成大陆与分形海岸（复用 `testworld::refine_borders`），结果是普通可编辑的地块。
- P0 **自动划分**：把所选陆地划成 N 个连通单位，可要求面积大致均衡、尽量沿河流与山脊；可用于国家，也可用于省。给出候选方案供选择。
- P0 **名称生成器**：离线，按音节风格生成国名、地名、人名；可锁定风格到文化层的单位。
- P0 **自定义历法**：纪元名称、起始年、年号显示格式；内部仍为整数年份，旧工程不变。
- P1 **事件时间线**：把同一年的一组变化命名为事件（战争、条约、继承），可附文字说明；时间轴按事件跳转；可导出编年表。
- P1 **河流生成**：按高程自动走向，可手动修正；与"尽量沿河流划界"配合。
- P1 **自动配色**：相邻国家不同色（图着色），一键重配。
- P1 **随机历史**：按参数生成一段可编辑的历史（测试世界生成器的产品化）。
- P1 **道路与旅行**：城市间路线生成；按速度估算旅行时间（已有测量工具）。
- P2 气候与生物群系层；旗帜与纹章图片；外交关系层；可交互网页导出（带时间轴的单文件 HTML）。

### 4.6 性能（持续）

预算（超出即视为缺陷）：

| 场景 | 预算 | 现状 |
|---|---|---|
| 空闲 CPU | 小于单核 2% | 21%（待修） |
| 每帧（百万三角形） | 小于 16 ms | 8 ms |
| 切换年份（百万三角形） | 小于 33 ms | 平均 6.9，最慢 22 |
| 局部编辑（常规地图 / 百万三角形） | 小于 50 ms / 小于 200 ms | 6 ms / 110 ms |
| 启动 | 小于 2 s | 1.16 s |
| 打开 20 MB 工程 | 小于 0.5 s | 59 ms |

- P0 **按需重绘**（见 §6 缺陷 3）。
- P1 **细节层次**：每条边按缩放级别预先简化，远看时只画简化线。现在无论缩放多远都画全部顶点，是三百万三角形以上的主要开销。
- P1 **索引网格**：顶点去重，内存约降到三分之一。
- P1 **大图局部编辑**：布尔运算只取多边形附近的边界片段，而不是整个面；耗时不再随面的顶点数增长（现在 1 km 细化时改 9 个面要 0.46 s）。
- P1 **基准入持续集成**：`map_bench` 的关键数值设阈值，回退即失败。
- P2 标注与专题计算移到后台线程；超大导出分块；栅格层的瓦片缓存。

## 6. 潜在缺陷清单

### 6.1 本次审计确认的缺陷

| # | 缺陷 | 影响 | 原因 | 状态 |
|---|---|---|---|---|
| 1 | 未选年份时把陆地改为水域，切换年份或重新打开后，该水域又算进原国家的面积 | 面积与由面积派生的统计错误 | 全量刷新归属时只对"有海陆历史"的面去掉归属，固定为水的面漏掉 | 已修复（M6 第一步） |
| 2 | 在目标实体不存续的年份合并或删除实体，土地暂时显示在不存续实体名下 | 显示不一致，下次刷新后恢复 | 单面刷新没有应用存续期（存续期功能加入时的遗漏） | 已修复（M6 第一步） |
| 3 | 空闲时持续重绘 | 空闲占单核 21%，笔记本耗电与风扇 | 每帧设置窗口标题会请求重绘 | 已修复：实测 10 秒 109 ms，约 1% |

- 缺陷 1、2 由随机压力测试发现。临时修复后 204 项测试与 9 782 次随机操作全部通过；补丁与测试当时尚未入库。
- 缺陷 3 修复时要同时排查依赖连续重绘的地方（例如导出窗口关闭后批量导出的完成提示）。

### 6.2 已知未解决

| 问题 | 说明 |
|---|---|
| 快速连点后双击结束绘制 | 有一次未能复现的失败 |
| 斜线区域跨日界线或在球背面 | 只画边线，不画图案与名称 |
| 无法绘制包围极点的陆地 | 已修复（M6 第七步）：极地大陆、其上的国家与湖泊都可以绘制；环形陆地在 0° 经线处分成两个面。导入时洞包围极点的多边形仍不支持 |
| 切分面的三处旧缺陷 | 已修复（M6 第七步，压力测试加入极地后查出）：紧挨起点的小段边界被漏检、切割线穿过已有顶点、一步横跨 180° 经度 |
| 封闭海峡后拓扑无效 | 已修复（M6 第二步）：新陆地把一片海围成内海时，局部重建仍把它算作背景海，拓扑无效；现在退回整体重建，内海成为独立水面。此前"北岸一次局部重建退回"是同一原因，属正当退回 |
